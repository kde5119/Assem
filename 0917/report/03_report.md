**1.** Provide examples of three different instruction mnemonics.

> 답: little endian은 LSB부터 낮은 메모리 주소에 저장. big endian은 MSB부터 낮은 메모리 주소에 저장함. 걸리버 여행기에서 계란을 어느 끝부터 깰 것인가로 전쟁을 벌였다는 이야기에서 유래하였음.

**8.** How are data labels and code labels different?

> 답: 데이터는 변수, 코드는 실행할 명령어의 위치를 지칭함

## 3.10 Programming Exercises

**1.** Integer Expression Calculation ⭐

Using the AddTwo program from Section 3.2 as a reference, write a program that calculates the following expression, using registers: A = (A + B) − (C + D). Assign integer values to the EAX, EBX, ECX, and EDX registers.

> 답:

```asm
.386
.model flat,stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.code
main PROC
    mov eax, 4         ; A = 4
    mov ebx, 3         ; B = 3
    mov ecx, 2         ; C = 2
    mov edx, 1          ; D = 1

    add eax, ebx        ; A = A + B = 4 + 3 = 7
    add ecx, edx        ; C = C + D = 2 + 1 = 3
    sub eax, ecx        ; A = A - C = 7 - 3 = 4

    INVOKE ExitProcess, 0
main ENDP
END main
```

**6.** AddVariables Program ⭐⭐⭐

Modify the AddVariables program so it uses 64-bit variables. Describe the syntax errors generated by the assembler and what steps you took to resolve the errors.

> 답: 64비트 변수로 바꾸면 레지스터도 64비트 레지스터로 변경해야 함. 그런데 32비트 환경에서는 64비트 레지스터를 인식하지 못함. 그래서 64비트 환경으로 변경. .386 등을 제거함. Windows API 호출 규약을 변경해야 한다.

```asm
ExitProcess PROTO

.data
    firstval  QWORD 2000200020002000h    ; 64비트 정수
    secondval QWORD 1111111111111111h
    thirdval  QWORD 2222222222222222h
    sum       QWORD 0

.code
main PROC
    mov rax, firstval        ; 64비트 RAX 레지스터 사용
    add rax, secondval
    add rax, thirdval
    mov sum, rax

    mov rcx, 0               ; 64비트 Windows ABI: 첫 번째 인자는 RCX
    call ExitProcess         ; 정식 API 호출
main ENDP
END
```
